# 🗑️ Crumpled Paper Toss Physics Simulation

A 2D physics simulation of tossing a crumpled paper ball into a recycling bin, built with **Matter.js** rigid body physics and **p5.js**.

![Matter.js](https://img.shields.io/badge/Matter.js-black?style=for-the-badge)
![p5.js](https://img.shields.io/badge/p5.js-ED225D?style=for-the-badge&logo=p5dotjs&logoColor=white)

## ⚡ Physics Features
- 📄 **Paper Class (`paper.js`)**: Circular rigid body with restitution (0.3) and friction (0.5).
- 🗑️ **Dustbin Class (`dustbin.js`)**: Constructs a static container boundary.
